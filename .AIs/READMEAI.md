# Central de agentes

```
.AIs/
├── AGENTS.md       # Regras universais para todas as IAs
├── docs/           # Documentação, planos, problemas, logs e contextos globais
└── configs/        # Configurações específicas por IA
    ├── codex/
    └── opencode/
```

As pastas legadas `.AIs/configs/.codex` e `vault/` continuam preservadas para
compatibilidade e histórico. `.AIs/configs/.opencode` mantém somente a configuração
e a orientação específicas do OpenCode. Novos documentos devem usar
`.AIs/docs/`; novas configurações devem usar `.AIs/configs/`.
