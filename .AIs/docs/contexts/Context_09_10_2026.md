## Lições sobre o fluxo com o Stitch

- `generate_screen_from_text` e `edit_screens` via MCP costumam estourar o
  tempo limite e **as edições via API não são gravadas** de forma confiável.
  O caminho que funciona é editar pela interface do Stitch (Claude in Chrome
  com a conta dona) e depois conferir pela API (`get_screen` muda o nome do
  arquivo HTML quando a edição é salva).
- `get_project` mostra uma cópia antiga do tema; para o DESIGN.md real use
  `list_design_systems`.
- As miniaturas do canvas demoram a atualizar. Para revisar, baixar o HTML e
  renderizar localmente no Edge headless em 1280 × altura do frame.
- No canvas, selecionar várias telas com a ferramenta de seleção retangular;
  Shift+clique arrastou uma tela por engano.
- Ao colar SVG com `xmlns="http://www.w3.org/..."` o Stitch anexa "w3.org"
  como contexto; omitir o `xmlns`.
