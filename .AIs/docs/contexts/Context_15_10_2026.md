## Como retomar

1. `git status -sb` para confirmar a branch e as mudanças pendentes.
2. Em `services/dashboard`, rodar `npm run test:unit` (esperado: 449/449) e
   `npm run build`.
3. Para ver o app: `npm run dev` em `services/dashboard`; o Electron abre
   sozinho e o Vite serve em `http://localhost:5173`. As preferências das
   Configurações ficam salvas no `localStorage` do app.
4. Revisar as telas e os itens "a validar". Commitar em pequenos commits
   (sugestão: um por tela, mais um para unidades e preferências, que
   tocam várias telas).
5. Depois: decidir quando levar a branch para a `master` (PR), alinhar com a
   equipe a decisão de manter o Electron e começar a Fase 5.
