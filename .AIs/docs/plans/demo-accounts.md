# Contas de demonstração

Usuário autorizou criar USER e ADMIN no banco do backend atual em desenvolvimento,
acessado pelo Docker local. Banco remoto não implica deploy da aplicação.

Criar apenas registros novos, numa transação, com emails reservados `.invalid`,
senhas aleatórias com bcrypt e veículos exclusivos de cada conta. Não sobrescrever
contas existentes. Popular instalações, configuração, ensaios planejados e
concluídos, telemetria sintética e resumos pelo calculador existente.

Executar script pontual em output/desktop-delivery (ignorado), sem ler .env,
alterar schema, código de produto ou publicar serviços. Validar hashes, papéis,
quantidades, login HTTP e acesso aos veículos. Credenciais entregues só ao usuário.
